== Services and Operations

[[EVSEAssignmentInfo]]
=== EVSE Assignment Info

API for assigning EVSEs to current EVSE Groups.

When you assign EVSEs to a group, the API will rewrite the assignment for that specific group, but other groups remain untouched. For example, if you assign EVSEs to `group1`, only `group1` will be updated while `group2` and any other groups retain their existing assignments.

[[Setup]]
=== Setup

As a Partner, before EVSE assignment, you have to create EVSE network and group and push EVSEs. For example, here we have created a network as `network1` and two groups as `group1` and `group2`. If you use the examples from the use cases below, please change the external id, network name, group name, and EVSE id according to your setup.

[[Endpoints]]
=== PUT Endpoints:

- QA env: https://service-qa.hubject.com/api/evsenetwork/v1/operators/{operatorId}/network
- PROD env: https://service.hubject.com/api/evsenetwork/v1/operators/{operatorId}/network

Rate limit: 50
